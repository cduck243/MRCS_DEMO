## 1. 계산 로직

### 1.1 전체 흐름

```
[입력]  성별 · 위험인내수준 · 월 가계지출 · 선택 분야 · 보유 담보
   ↓
[통계]  질병군별 1인당 본인부담 의료비 / 입내원일수 / 명세서 건수  (성별 · Min·Avg·Max)
   ↓
[필요]  필요금액 = 병원비 + 생활비
          병원비 = 통계값 × 진단1년차계수 × 경과시나리오배수 × (1+비급여계수)
          생활비 = 월 가계지출 × 소득 단절 개월수
   ↓
[준비]  실손    = 급여본인부담×80% + 비급여×70% (약관 면책 반영, 한도 5,000만)
        정액 6종 = 진단 + 수술 + 치료 + 입원 + 통원 + 간병
   ↓
[표시]  내가 낼 병원비 = 병원비 − 실손          (금액)
        정액 커버율   = 정액 ÷ (내가 낼 병원비 + 생활비)   (%)
        부족액 · 보장 유무 7칸 (있음 / 없음 / 해당없음 / 보장 밖)
```

### 1.2 의료비

```
1인당 본인부담 의료비 = (요양급여비용총액 − 보험자부담금) ÷ 환자수
```

- 질병군(중분류) 범위에 속한 3단코드들을 모아 분포를 만든다
- `Min` = 분포 최솟값 / `Avg` = 환자수 가중평균 / `Max` = 분포 최댓값
- 환자수 30명 미만 코드는 이상치로 제외 (남는 코드가 2개 미만이면 전체 사용)
- 성별로 각각 산출한다 (남 / 여 / 전체)

건강보험 청구자료에는 **급여 항목만** 담긴다. 선택진료·상급병실·신의료기술·도수치료 같은
**비급여는 빠져 있어** 위 값을 그대로 쓰면 실제 병원비를 크게 낮춰 잡는다.
그래서 분야(대분류)마다 가산계수를 곱해 보정한다.

```
필요 의료비 = 1인당 본인부담 의료비 × (1 + 비급여 가산계수)

비급여 가산계수 = 해당 분야 비급여 비중 ÷ 해당 분야 법정 본인부담 비중
```

근거 — 국민건강보험공단 「2024년 건강보험 환자 진료비 실태조사」 보장률 (2025.12.30 공표)

| 구분 | 보장률 | 법정 본인부담 | 비급여 | 가산계수 |
|---|---|---|---|---|
| 전체 (기본값) | 64.9% | 19.3% | 15.8% | **0.82** |
| 암 | 75.0% | 9.0% | 16.0% | **1.78** |
| 뇌혈관질환 | 87.9% | 6.4% | 5.7% | **0.89** |
| 심장질환 | 90.3% | 4.9% | 4.8% | **0.98** |
| 희귀·중증난치 | 89.3% | 8.1% | 2.6% | **0.32** |
| 병원급 | 51.1% | 18.1% | 30.8% | **1.70** |
| 의원급 | 57.5% | 20.1% | 22.4% | **1.11** |

### 1.3 위험인내수준 = 경과 시나리오

기존에는 `Min` / `Avg` / `Max`, 즉 **질병군 안에서 어느 3단코드를 볼 것인가**였다.
그런데 폭이 거의 없다 — 대장암은 C18~C21 네 코드가 45 / 49 / 54만원이다.
인내수준을 바꿔도 숫자가 거의 그대로여서 레버가 죽어 있었다.

이제 **병이 어떻게 흘렀는가**의 시나리오 배수로 다시 정의한다.

| 위험인내수준 | 경과 | 배수 | 통계값 |
|---|---|---|---|
| 안정우선형 | 최중증 경과 | **×4.0** | `Max` |
| 균형준비형 | 중증 경과 | **×2.0** | `Avg` |
| 위험수용형 | 평균 경과 | **×1.0** | `Min` |

**왜 배수가 필요한가** — 공단 통계의 1인당 값은 그 상병으로 진료받은 사람
전체의 평균이라, 비급여를 많이 쓴 사람의 부담이 묻힌다.
한 사람에게 몰리는 비급여는 이 정도다.

| 항목 | 금액 |
|---|---|
| 로봇수술 | 800~1,500만원 |
| 상급병실 차액 | 1일 10~30만원 |
| 비급여 항암제 | 연 수천만원 |

앵커 — Kim SY 외, 「Costs of Initial Cancer Care and its Affecting Factors」,
*J Prev Med Public Health* 42(4), 2009 (국립암센터).
폐암 진단 후 1년 총비용 2,565만원, 환자 본인부담이 총비용의 50% 초과.

> **주의** 1.0 / 2.0 / 4.0 은 **가정값**이다. 개인별 부담 분포를 담은 공식 통계가
> 없어 비급여 항목 단가와 위 연구를 근거로 잡았다.
> 실손 청구·지급 데이터가 확보되면 실측 분포로 교체해야 한다.
> 배수는 `build_step4.py` 의 `ATTITUDES` 한 곳에서 바꾼다.

### 1.3b 진단 1년차 집중 계수

통계의 분모(환자수)에는 수술·항암 중인 환자와 완치 후 추적관찰만 받는 환자가
함께 들어간다. MRCS가 필요로 하는 값은 **진단 후 1년차**이므로 보정한다.

근거 — Shin JY 외, 「Costs During the First Five Years Following Cancer Diagnosis
in Korea」, *Asian Pacific J Cancer Prev*, 2012 (국립암센터). 신규 진단자 28,509명 5년 추적.

| 암종 | 1년차 | 5년 누적 | 1년차 비중 |
|---|---|---|---|
| 폐암 | $12,896 | $20,217 | 64% |
| 대장암 | $11,024 | $17,928 | 62% |
| 유방암 | $10,053 | $18,242 | 55% |

유병자 1인당 연간 평균은 5년 누적을 고르게 편 값(≒20%)에 가까우므로
`1년차 ÷ 유병자 평균 ≒ 60 ÷ 20 = 3.0배`.

| 대분류 | 계수 |
|---|---|
| 암과 종양 (KCD02) | **3.0** |
| 그 밖의 질환군 | 1.0 (미적용) |

> 뇌졸중·심근경색처럼 급성기에 비용이 몰리는 질환도 실제로는 보정이 필요하다.
> 같은 성격의 국내 코호트 연구를 확인하지 못해 적용하지 않았다.

### 1.4 소득 단절 개월수

치료 기간이 아니라 **일을 못 하게 되는 기간**을 뜻한다.
상급종합병원의 평균 입원일수는 7일 안팎이고 그 이상은 통원이나 다른 병원 진료인데,
그 정도로 치료가 길어지면 다니던 일을 그만두는 경우가 대부분이라는 전제다.

```
① 요양개월 R = 1인당 명세서 건수 × 0.7
② 후유장해 배수 f
     rare       1.0
     sometimes  1.5
     often      2.0
③ 가산
     중증  = (후유장해 often) AND (사망 often OR 간병 often OR 입내원 30일 이상)
             → +30개월
     후유장해 often (중증 아님)      → +6개월
     후유장해 sometimes             → +1개월
     사망 often (중증 아님)          → +6개월 추가
④ raw = R × f + 가산
⑤ 구간 정렬
     raw < 3      →  0개월   연차·병가로 감당
     raw < 4.5    →  3개월   단기 휴직
     raw < 7.5    →  6개월   장기 휴직
     raw < 10.5   →  9개월   휴직 후 복직 준비
     raw < 15     → 12개월   실직 후 재취업
     raw < 21     → 18개월   장기 실직
     raw < 30     → 24개월   장기 실직
     raw ≥ 30     → 36개월   경력 단절
```

검증 결과

| 질병 | 명세서 | 후유장해 | raw | 결과 |
|---|---|---|---|---|
| 장염 | 1.6건 | 드묾 | 1.1 | 0개월 |
| 백내장 | 2.7건 | 드묾 | 1.9 | 0개월 |
| 폐렴 | 1.9건 | 경우따라 | 3.0 | 3개월 |
| 협심증·심근경색 | 3.0건 | 경우따라 | 10.1 | 9개월 |
| 유방암 | 9.3건 | 경우따라 | 16.8 | 18개월 |
| 뇌졸중 | 3.8건 | 흔함 (중증) | 35.3 | 36개월 |
| 치매 | 4.3건 | 흔함 (중증) | 36.0 | 36개월 |
| 만성신부전 | 22.7건 | 흔함 (중증) | 61.8 | 36개월 |

> **미반영** 실업급여(구직급여) · 상병수당 · 변동수입 공제.
> 이 셋을 차감하면 생활비 필요액이 줄어든다.

### 1.5 필요금액

```
급여 본인부담 = 1인당 본인부담 의료비                        ← 1.2 통계값
              × 진단 1년차 계수                            ← 1.3b
              × 경과 시나리오 배수                          ← 1.3
비급여 추정액 = 급여 본인부담 × 비급여 가산계수                ← 1.2
필요 병원비   = 급여 본인부담 + 비급여 추정액
생활비        = 월 가계지출 × 소득 단절 개월수                ← 1.4
필요금액      = 필요 병원비 + 생활비
구간          = 필요금액 × (1 ± 1.96 × 0.10) = ±19.6%   (95% 신뢰구간 · 변동율 10%)
```

대장암(남성) 예시 —

| 인내수준 | 급여본인 | 비급여 | 필요 병원비 | 실손 | 내가 낼 병원비 |
|---|---|---|---|---|---|
| 안정우선형 ×4 | 605만 | 1,077만 | 1,681만 | 1,237만 | **444만** |
| 균형준비형 ×2 | 292만 | 520만 | 812만 | 598만 | **214만** |
| 위험수용형 ×1 | 118만 | 209만 | 327만 | 241만 | **86만** |

**분야(대분류)의 값**은 그 안에 속한 질병군을 평균 내지 않는다.
평균을 내면 경증까지 섞여 실제 부담이 가려지므로, **필요금액이 가장 큰 질병군**을 대표로 쓴다.

**여러 분야를 골라도 합산하지 않는다.** 한 번에 한 가지가 발생한다고 보고,
고른 분야 중 가장 부담이 큰 것을 대표값으로 삼고 나머지는 범위로 표시한다.

### 1.6 준비금액

담보별 지급 예상액을 더한다.

| 급부 | 산출식 |
|---|---|
| 진단 | 가입금액 |
| 수술 | 가입금액 |
| 치료 | 가입금액 |
| 입원 | 일당 × 입내원일수 (반올림, 최소 1일) |
| 통원 | 회당 × 횟수 (소득단절 12개월↑ → 12회 / 6개월↑ → 6회 / 그 외 1회) |
| 간병 | 일당 × 일수 |
| 실손 | 아래 산식 (급여와 비급여의 자기부담률이 다르므로 나눠서 계산) |

```
실손 보전액 = min( 급여 본인부담 × 0.80 + 비급여 추정액 × 0.70 , 연간한도 5,000만 )

  급여 본인부담 = 1인당 본인부담 의료비              ← 1.2 통계값
  비급여 추정액 = 급여 본인부담 × 비급여 가산계수      ← 1.2 계수
  0.80 / 0.70   = 4세대 실손 급여 / 비급여 보상비율   (policy.indemnity 에서 조정)
```

### 1.6b 정액과 실비의 분리 — 가장 중요한 규칙

이전 정의는 이랬다.

```
병원비 보장 = 수술 + 치료 + 입원 + 통원 + 실손
```

이렇게 하면 **16개 분야 중 15개가 "충분"**으로 나온다. 산수를 보면 이유가 분명하다.

```
병원비 준비율 = ( 정액 1,630만 + 실손 74% × 필요 ) ÷ 필요  ≥ 1
              ⟺  필요 병원비 ≤ 6,174만
```

**필요 병원비가 6,174만원을 넘기 전까지는 어떤 계수를 써도 "충분"이 나온다.**
분모를 ×8 해도 충분이다. 즉 분모를 올려서 고칠 수 있는 문제가 아니었다.

수술비 500만원은 병원비를 대신 내라고 주는 돈이 아니라 **용도가 정해지지 않은 현금**이다.
실제 병원비를 메우는 것은 실손뿐이다. 그래서 이렇게 나눈다.

```
[ 병원비 쪽 ]  내가 낼 병원비 = 필요 병원비 − 실손 보전액          → 금액으로 표시

[ 정액 쪽 ]    정액 6종 = 진단 + 수술 + 치료 + 입원 + 통원 + 간병
               필요액   = 내가 낼 병원비 + 끊긴 생활비
               정액 커버율 = 정액 6종 ÷ 필요액                    → % 로 표시

준비율(종합) = (실손 + 정액 6종) ÷ 필요금액
```

정액은 용도가 정해지지 않은 현금이라 실제로 이 둘을 함께 감당한다.

**병원비 칸을 % 가 아니라 금액으로 두는 이유** — 실손이 있으면 병원비의 74~78%는
구조적으로 메워져서 분야가 달라도 비율이 거의 변하지 않는다.
변하는 것은 '내가 낼 금액'이고, 그게 읽을 가치가 있다.

100%를 넘으면 숫자 대신 **충분**으로 표시한다.

**준비율 % 는 대분류 단위와 중분류 단위에서만 표시한다.**
화면 전체를 하나의 % 로 묶지 않는다. 질병마다 필요 금액이 다르고 합산 대상이 아니어서
전체 준비율은 숫자만 남고 뜻이 사라진다(예: `준비율 7%`). 상단은 % 대신
`비어 있는 금액 · 보장 공백 · 내가 낼 병원비 · 정액으로 감당` 네 가지 사실만 둔다.

**후유장해 · 사망 · 위로금 · 비용지원**은 질병군별 계산에 넣지 않는다.
어느 병으로 얼마의 장해가 남을지 미리 정할 수 없고,
사망보험금은 본인 치료비가 아니라 유족 생활비여서 성격이 다르다.
별도 섹션에 보유 여부와 금액만 표시한다.

### 1.7 보장 유무 판정

```
약관상 보장 대상이 아니거나 담보 자체가 없음      → 보장 밖 (!)
필요도(benefitNeed)가 rare 또는 none          → 해당없음 (–)
해당 담보코드를 하나도 보유하지 않음 또는 금액 0  → 없음 (✕)
그 외                                        → 있음 (✓)
```

담보코드는 질병군 → 카테고리 → 대표 담보코드로 매핑한다.
카테고리는 `cancer` / `cerebro` / `cardio` / `dementia` / `injury` / `disease` 여섯이다.

**`보장 밖`을 `없음`과 나누는 이유** — '필요한데 내가 안 든 것'과
'보험이 아예 다루지 않는 것'은 다르다. 섞으면 준비하면 채울 수 있는 것처럼 읽힌다.
보장 밖 칸은 `보장 n / m 준비됨`의 **분모에서 뺀다.**

실손의료보험 표준약관 (2016.1 개정 이후 · 4세대 기준) —

| 대상 | 코드 | 급여 | 비급여 |
|---|---|---|---|
| 정신 및 행동장애 | F04~F99 | F04-F09·F20-F29·F30-F39·F40-F48·F51·F90-F98만 보상 | **전면 면책** |
| 치매 | F00~F03 · G30 | 보상 | 보상 (면책 범위 밖) |
| 임신·출산·산후기 | O00~O99 | **면책** | **면책** |
| 선천성 뇌질환 | Q00~Q04 | **면책** (가입 당시 태아면 예외) | 동일 |
| 치과치료 | K00~K08 | 보상 | **면책** |
| 한방치료 | — | 보상 | **면책** (의사 시행분 예외) |

> 5세대 실손(2026.5.6 출시)부터 임신·출산 급여 의료비가 신규 보장되고,
> 태아 때 가입한 경우 18세까지 발달장애 치료를 보장한다고 발표되었다.
> 약관 원문을 확인하지 못해 4세대 기준으로 계산한다.

**정액담보** — 한국신용정보원 146개 담보코드에 정신질환의 진단·수술·치료 담보가 없다.
치매만 `A4109`(치매진단) · `A4110`(경증치매)로 존재한다.
2025년 이후 정신질환 진단비를 다루는 상품이 나오기 시작했으나
표준 담보 체계에는 아직 들어와 있지 않다.

## 2. 표시 데이터

### 2.1 화면 구조

```
① 조건 바 (읽기 전용)        성별 · 위험인내수준 · 월 가계지출 · 비상자금
② 상단 요약 4칸              비어 있는 금액 · 보장 공백 · 내가 낼 병원비 · 정액으로 감당
                            (전체 준비율 게이지는 두지 않는다 — 1.6b 참조)
③ 읽는 방법 버튼             모달
④ 분야별 준비 정도           대분류 행 → 펼치면 중분류 행
⑤ 실손 보장 범위             메워 주는 것 / 메워 주지 않는 것
⑥ 질병과 따로 준비되는 보장    후유장해 · 사망 · 위로금 · 비용지원
⑦ 확인 안내 · 근거 출처
```

### 2.2 행에 표시하는 것

| 위치 | 내용 |
|---|---|
| 왼쪽 | 질병명 (소비자용) + 한줄설명 |
| 가운데 | 준비율 % + 막대 + `내 병원비 456만 · 정액 30% · 부족 10,732만` |
| 오른쪽 | `보장 4 / 6 준비됨` + 급부 7칸 (✓ 있음 / ✕ 없음 / – 해당없음 / ! 보장 밖, 금액 병기) |
| 끝 | 대분류는 `질병 21개 ▾` · 중분류는 `자세히 ›` |

**화면에 노출하지 않는 것** — KCD 코드, 요양개월, 명세서 건수, 배수·가산 같은 내부 지표.
이것들은 우리 로직이지 소비자가 읽을 정보가 아니다.

### 2.3 상세 모달 (자세히)

```
질병명
한줄설명

병원비 충분 │ 생활비 10% │ 필요한 금액 5,070만 │ 비어 있는 금액 4,357만

병원비 142만
  = 건강보험이 인정하는 진료비 중 내 몫 78만 + 비급여 추정 64만

비어 있는 보장
  치료   (그 급부가 왜 필요한지 설명)
  간병   (〃)

준비된 보장
  진단   특정질병진단              500만
  입원   질병입원일당               15만
  실손   4세대 실손                63만

이 병에는 수술 보장이 크게 필요하지 않습니다.
```

산식은 보여 주지 않는다. **비어 있는 보장이 맨 위**에 온다.

### 2.4 색 규칙

| 상태 | 색 | 조건 |

| 충분 | 초록 | 준비율 80% 이상 |
| 부족 | 주황 | 0% 초과 80% 미만 |
| 없음 | 빨강 | 0% |
| 해당없음 | 회색 | 그 병에 필요하지 않은 보장 |

### 3.3 보유 담보 — 신용정보원 조회 결과

```json
{
  "indemnity": {
    "generation": "4세대",
    "rateBenefit": 0.80,        // 급여 지급 비율 (자기부담 20%)
    "rateNonBenefit": 0.70,     // 비급여 지급 비율 (자기부담 30%)
    "limit": 5000               // 연간 한도 (만원)
  },
  "covers": [
    { "code": "A4200", "name": "암진단",      "amount": 3000 },
    { "code": "A6200", "name": "암입원일당",   "amount": 5, "perDay": true },
    { "code": "A7100", "name": "질병통원",     "amount": 3, "perVisit": true }
  ]
}
```

| 필드 | 설명 |
|---|---|
| `code` | 한국신용정보원 표준 담보코드 (146종) |
| `name` | 담보명 |
| `amount` | 가입금액 (만원) |
| `perDay` | true면 일당 담보 — 일수를 곱한다 |
| `perVisit` | true면 회당 담보 — 횟수를 곱한다 |

실손은 담보코드 체계와 별도로 관리되므로 `indemnity` 객체로 따로 받는다.

### 3.4 질병 마스터 — 서버가 내려주는 데이터

```json
{
  "code": "I60-I69",
  "name": "뇌졸중 (뇌혈관 질환)",
  "oneLiner": "뇌의 혈관이 막히거나 터져서 생기는 병입니다.",
  "majorId": "KCD09",
  "majorName": "심장과 혈관 질환",
  "category": "cerebro",
  "subject": "self",
  "nonBenefit": 0.95,
  "firstYear": 1.0,
  "scopeOut": [],
  "scopeNote": "",
  "indem": { "rateB": 1.0, "rateN": 1.0, "note": "" },
  "benefitNeed": {
    "diagnosis": "often", "surgery": "sometimes", "therapy": "often",
    "admission": "often", "outpatient": "often", "care": "often",
    "disability": "often", "death": "often"
  },
  "benefitNote": { "care": "마비나 언어장애가 남으면 일상 돌봄이 필요합니다." },
  "coverCodes": {
    "diagnosis": ["A4101", "A4102", "A4103"],
    "surgery": ["A5104"], "therapy": ["A9600"],
    "admission": ["A6107"], "outpatient": ["A7100"],
    "care": ["A8000", "A4503"]
  },
  "stat": {
    "applies": "both",
    "m": { "cost": {"min":16,"avg":52,"max":199},
           "days": {"min":3.1,"avg":11.0,"max":43.8},
           "claims": {"min":1.2,"avg":3.8,"max":9.1},
           "patients": 412330, "codes": 10 },
    "f": { "...": "동일 구조" },
    "all": { "...": "동일 구조" }
  }

```

`benefitNeed` 값은 `often` · `sometimes` · `rare` · `none` 넷 중 하나다.
`nonBenefit` 은 비급여 가산계수(1.2), `firstYear` 는 진단 1년차 계수(1.3b)다.
`scopeOut` 은 약관상 보장 대상이 아닌 급부 키 목록, `indem` 은 실손 적용 배율이다.
`indem.rateB` / `rateN` 은 급여 본인부담 · 비급여에 각각 곱하는 값으로 `0` 이면 면책이다.
금액 단위는 모두 **만원**, 일수는 **일**, 건수는 **건**이다.

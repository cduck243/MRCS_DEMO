**데모** → https://cduck243.github.io/MRCS_DEMO/

빌드 도구 없이 열립니다. `index.html` 을 더블클릭하면 그대로 동작합니다.

로컬 AI로 5단계 문장을 다시 쓰는 기능은 [`실행방법.md`](실행방법.md) 를 보십시오.
문장은 컴퓨터 안에서 만들어지고 밖으로 나가지 않습니다.

## 계산의 뼈대

```
필요 병원비 = 1인당 급여 본인부담
              × 진단 1년차 계수      (암 3.0)
              × 경과 시나리오 배수   (평균 1.0 / 중증 2.0 / 최중증 4.0)
              × (1 + 비급여 가산계수)

필요 생활비 = 월 가계지출 × 소득 단절 개월수 (0~36)

내가 낼 병원비 = 필요 병원비 − 실손 보전액
정액 커버율    = 정액 6종 ÷ (내가 낼 병원비 + 필요 생활비)
```

정액담보를 병원비 분모에 넣지 않는 것이 핵심입니다. 병원비를 실제로 메우는 것은 실손이고,
정액은 실손이 못 메운 자기부담과 끊긴 생활비를 함께 감당하는 현금으로 봅니다.

자세한 내용은 [`docs/개발정의서_STEP4.md`](docs/개발정의서_STEP4.md)와
[`docs/개발정의서_STEP5.md`](docs/개발정의서_STEP5.md)에 근거와 함께 있습니다.

## 확인 안내

예시용 시연 화면입니다.

- 질병 설명 212건은 **의료전문가 검수 필요** 상태입니다.
- 보유 담보와 금액은 **가상의 예시**입니다. 실제 서비스에서는 신용정보원 보험정보 조회로 대체됩니다.
- 경과 시나리오 배수(1.0 / 2.0 / 4.0)는 **가정값**입니다. 실손 청구 데이터로 교체해야 합니다.
- 특정 보험회사의 상품을 권유하지 않습니다. 비어 있는 보장의 유형만 정리합니다.
- 정확한 진단과 치료 방법은 의료기관과 의료진의 확인을 받아야 합니다.
